# Clínica (prueba)

Página web de prueba de la aplicación de la clínica, con datos inventados.

- `index.html`: la aplicación. La actualiza Claude cuando se le pide un cambio.
- `config.js`: los datos del proyecto de Firebase. No hay que tocarlo.

Los datos no están aquí: se guardan en Firebase y solo se ven entrando con un usuario.
